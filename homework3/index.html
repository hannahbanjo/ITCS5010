About the Model

Win probabilities are computed using a logistic regression model trained on 2020–2024 FBS game data. The model uses game-level differential features: turnover margin, passing yards differential, rushing yards differential, first downs differential, third-down conversion rate differential, penalty yards differential, time of possession differential, and home-field advantage.
